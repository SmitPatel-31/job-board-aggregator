# data

Inputs and generated state for the scraper.

Tracked here:

- `*_companies.json` — company/slug lists per ATS platform
- `locations.json` — city gazetteer used to resolve locations and countries
- `salary/` — static salary estimate lookup, sharded a-z
- `role_filter.json` — role preset: include/exclude patterns, levels, region
- `role_shortlist.json` — fast-tier target companies, regenerated by each full scrape
- `app_config.json` — front-end runtime config
- `trends/daily.jsonl` — append-only per-platform counts, one JSON object per line

Not tracked (see `.gitignore`):

- `chunks/` — the generated dataset (~74MB of gzipped JSON). It is published
  with the site to GitHub Pages as a build artifact, so it never enters git
  history. Committing regenerated chunks is how the upstream repository's
  `.git` reached 6GB.
- `metadata.json` — counts from the last merge
- `dead_slugs/` — cache of slugs that returned 404/410
